# SmokHive

A responsive e-commerce storefront for all-ages 3D-printed desk organizers, trays, containers, cable tools, and kits.

## Features

- Responsive graffiti-gallery interface
- Product search and category filtering
- Persistent shopping cart with quantity controls
- Free-shipping progress and checkout handoff
- Accessible mobile navigation and reduced-motion support

## Development

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.
